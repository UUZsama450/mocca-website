Frequently Asked Questions

常见问题

现在可以下载 Mocca 吗？

Mocca 的 iOS 版本正在准备上架。正式开放下载后，我们会在官网提供 App Store 入口。

Mocca 包含模型服务和使用额度吗？

Mocca 是聊天客户端，需要你自行添加兼容的模型服务商、API Key 和模型。模型调用的价格、额度和可用性由对应服务商决定。

群聊可以做什么？

你可以让多个助手加入同一段对话，并选择由谁回复。例如让灵感助手想点子、规划助手做计划，再请细节助手补充。

怎样开始聊天？

打开 Mocca 后进入“设置 → 供应商”，添加你使用的兼容服务商、API Key 和模型。保存后回到聊天页，选择模型即可开始。也可以在“设置 → 使用文档”查看操作说明。Mocca 本身不包含 AI 模型账户。

模型连接失败怎么办？

请依次检查服务商是否启用、API 地址是否正确、Key 是否有效、模型 ID 是否存在，以及服务商账户是否还有额度。不要把完整 API Key 发给任何人。

聊天和备份存在哪里？

聊天默认保存在当前设备。换机、卸载或清除 App 前，请先在 Mocca 中主动导出备份，并把文件保存在你信任的位置。

“投喂 Mocca”会自动续费吗？

不会。三个档位都是可选、可重复购买的一次性支持，不影响聊天功能，也不会自动续费。首次购买某个档位会永久留下对应的纯装饰纪念物。

为什么 App 会请求照片、位置或日历权限？

Mocca 只会在你实际使用对应功能时请求权限。例如发送图片、本地天气、创建日历事件或管理提醒事项；拒绝权限不会影响不相关的聊天功能。
